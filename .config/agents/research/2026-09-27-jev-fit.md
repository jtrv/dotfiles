# Jev (TypeSafe System One) — fit for this setup

Researched 2026-09-27. Raw community sweep: `2026-09-27-last30days-jev-raw.md`.

## What Jev is
Typed-decision model (launched in early access 2026-09-15). State text in; answers to predefined
Choice / Score / Noul questions out, each with calibrated probability and confidence. It does not
generate text. `jev-1.13.0`: $0.042 per Mtok input, output free, 250k tok/s and 1,200 req/min,
64k per request (32k state plus the longest question), text only, English best
(docs.typesafe.ai/models.md). Documented weak spots: literal reading, arithmetic, dates,
indirection, large irrelevant state and adversarial content (model-jaggedness/jev-1.13.md). The
vendor says it is not a drop-in model for coding agents (introduction/coding-agents.md).

## Observed agentic use (thin, mostly week-old repos)
- **Code-search rerank:** Oko MCP (github.com/bartlomein/oko). One Jev call scores the top 30 BM25
  hits. Over 162 sessions: Claude Code 31% faster, 20–42% fewer tokens. The gain only appeared
  after a "stop searching" rule was added to the agent instructions. One author, but the scripts
  are published.
- **Skill suggestion / model routing hooks:** jev-agent-hooks, skillpick, jev-router, tenjin. None
  of them publish measurements. The vendor cookbook (skill_suggestion.md, Haiku 4.5 agent,
  182-skill catalog) halved wrong skill loads (16.8% to 7.3%).
- **Command-safety gates and judge cascades:** the confident verdict passes and an uncertain one
  escalates to a big model. The evidence is single reports summarised on Digg.
- **Criticism:** it is "a zero-shot classifier" and "frontier" oversells it. It can still pick a
  wrong valid value. Speed comparisons against reasoning LLMs are apples-to-oranges. Its launch
  price may be subsidised.

## This setup, 2026-07-29 to 2026-09-27
- 407 Claude Code sessions, of which 264 (65%) are security-guidance plugin reviews on Opus 4.7.
  They take 76s median and produced 3.8M output tokens; 93% of their structured outputs were
  `findings: []`.
- remember plugin: 1,117 Haiku save calls ($29) plus 426 consolidation calls ($10). Only 37 saves
  ended in SKIP.
- block-secrets: 87 blocks plus 113 `SECRETS_OK=1` bypasses, about 100 of them false positives. The
  top rule is the `.key` suffix, which also matches jq `.key`; it fired three times in this session.
- Routing: 117 prompts name a model (mostly Astra); 68 codex-rescue dispatches.

## Verdict
| Candidate | Worth it? | Why |
|---|---|---|
| Gate security-guidance with one Noul ("diff touches security surface?") | Maybe: the only real win | It would skip most of 264 Opus runs for about $0.10 of Jev. First ask whether the plugin should run on every repo at all: scoping it costs nothing. Skipping on a wrong "no" is a security miss, so keep the threshold conservative. Diffs go to a third party. |
| block-secrets second stage | No | Fix the regex (anchor `.key` to path context). A network call on every tool call to cure a regex bug is backwards, and the commands would be sent to a third party. |
| remember pre-filter | No | Only 37 of 1,117 calls ended in SKIP, so there is little to cut. About $20 a month. |
| Routing-table classifier | No | The main model already holds the context. The manual model picks are preference, not error. |
| Skill pre-ranking | No for now | The cookbook gain was on Haiku with 182 skills. Here it is Opus with about 32 skills. |
| Oko-style code-search rerank | Optional trial | The only measured agent win in the wild. Cheap to A/B on one repo. |

Re-check trigger: published tier pricing and GA (no waitlist), or a measured
Jev-vs-Haiku comparison on gating tasks.
