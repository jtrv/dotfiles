Which doc tool for which question
=================================

Nix
---
wud find nix <name>  what does this lib function/builtin do (offline)
nh search <query>    what exists — packages on search.nixos.org (online), use
                     when you don't know the name yet; `nh search options` too
nixos-option <opt>   an option's docs + its value in MY evaluated config

CLI / system
------------
man <cmd>            the canonical reference once you know the page

Libraries / languages
---------------------
wud                  devdocs + built docsets offline (cargo-installed, synced in bootstrap.nix)
